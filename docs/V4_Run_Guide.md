## Run order (each = one Kaggle "Save & Run All (Commit)")
1. **A — `cascade_v4_A_pool_screens.ipynb`** (T4, ~2.5 h). Produces `v4_A_screens.npz`, `v4_pool.json`, `v4_data.json`, `v4_triggers.npz`, `v4_wgm.json`.
2. **C — `cascade_v4_C_gcg.ipynb`** (T4, ~5 h, resumable). Needs A's `v4_data.json`. Produces `v4_C_gcg.npz`.
3. **D — `cascade_v4_D_pair_e2e.ipynb`** (T4 + API, ~1.5 h). Hard $15 cap in code. Produces `v4_D_pair_e2e.json`.
4. **B — `cascade_v4_B_experts.ipynb`** (T4 ×2, ~2.5 h). Needs A's `v4_data.json` + `v4_pool.json`. Produces `v4_B_experts.npz`.
5. Run A's **merge cell** (Cell 6) with all four outputs present in `OUT` → writes `results/v4_scores.npz`.
6. Download `v4_scores.npz` and `v4_D_pair_e2e.json` into `Aegis/results/`, then locally:
   `python tools/v4_analysis.py results/v4_scores.npz`

**Sharing outputs between notebooks on Kaggle:** add the previous notebook's output as an input dataset, or run the later notebook in the same session after A if persistence is on. The merge cell also accepts files you upload as a dataset.

## What the analysis prints
- Per expert (E_LG, E_GR) × view (L0, raw): per-screen cascade-induced loss (H1), the policy sweep P0…PNE+ε with adaptive recall under A1/A4, natural recall and test/hard FPR (H2, H3), then H4 (enforcement separability) and H6 (price of delegation). H5 (end-to-end harm) prints if `v4_D_pair_e2e.json` is present.
- The H1 GO/NO-GO verdict is printed per expert/view.

## Guardrails already enforced in code
- $15 API cap (`vyuha/cascade/api.py`), AGENT_API_KEY read only from Secrets, never printed.
- Budget-matched calibration (triggers don't get a free budget); separate calib/test benign halves.
- L0 frozen at v2; held-out encodings (Atbash/Morse/binary/Vigenère/Base85) only as attacks.
- GCG success re-scored through the real L0→screen pipeline, not the raw search loss.
- Every stage checkpoints and resumes.
